# Verification checklist

## Data audit

- Match the output filename and applicant name to the same passport, COE, NRC, and personal-information record.
- Confirm DOB, sex, birthplace, NRC, passport number, passport dates, COE number, status, and stay length character-for-character.
- Confirm current address, telephone, mobile, and email against the personal-information sheet.
- Confirm accommodation name, address, and telephone against that student's Form 17.
- Confirm guarantor name, company, legal title, address, and telephone against the employment contract or a reliable primary/public source.
- Mark any estimated or user-specified testing value as unverified in the final handoff.

## PDF audit

- Compare each page with the supplied reference at the same rendered resolution.
- Check all values are on the intended baseline, above and close to the printed line.
- Check no value covers labels, `(Day)/(Month)/(Year)` hints, boxes, or existing entries.
- Search visually for names or company information belonging to the reference applicant.
- Confirm page count, A4 size, legibility, and absence of clipping or double text.
- If interactive, reopen and validate both field values and widget appearances.
- If static, confirm there are no widget annotations or AcroForm field tree.
