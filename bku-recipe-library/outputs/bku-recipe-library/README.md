# BKU レシピ・ライブラリ

BKU の業務を、誰でも再現できる「レシピ」として蓄積・改善するためのライブラリです。
レシピは人が作成・検証し、AI は整形・変換・実行補助に使います。業務の中身や判断基準を AI が勝手に作ることはありません。

## 使い方

1. `TEMPLATE.md` をコピーして、実際の業務を 1 つ選び、7 つの項目を埋める。
2. 実際に使い、出力を確認する。
3. `META_RECIPE.md` のチェック項目でレビューする。
4. レビュー済みのレシピを `recipes/<owner>/` に登録する。
5. 必要に応じて `scripts/recipe_to_skill.py` で Claude Skills 用に変換する。

## ルール

- レシピ本文は業務担当者が書く。Codex は構成、整形、変換を担当する。
- 人を評価するのではなく、レシピを改善する。
- 他人のレシピを変更する場合は、作成者に一声かける。
- 使用されなくなったレシピも削除せず、履歴を残す。
- 日本語を基本とし、必要な場合は英語版を同じ構成で追加する。

## ディレクトリ

| 場所 | 用途 |
|---|---|
| `recipes/kanako` など | 担当者別のレシピ |
| `recipes/shared` | 部門共通のレシピ |
| `skills` | Skills 変換後の成果物 |
| `scripts` | 補助スクリプト |

## 90日目の目安

レシピ15本以上、うち10本以上が月1回以上利用され、Kanako 以外のメンバーも各1本以上を作成・利用できる状態を目指します。ログイン数や利用率そのものを人の評価には使いません。
