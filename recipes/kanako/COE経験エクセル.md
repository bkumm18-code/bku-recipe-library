# COE経験エクセルを作る

## 1. 完成条件

パスポート、Final Excel List、履歴書から、指定形式・指定書式のCOE経験エクセルを作成する。

### 完成見本

## 2. 入力ファイル

### 必須
- パスポートPDFまたは画像
- Final Excel List.xlsx
- 履歴書ファイル

### 使用しないもの
- 過去に作成された完成済みExcel
- 対象者と一致しない履歴書

## 3. 情報源の優先順位

| 情報 | 第1優先 | 第2優先 | 不一致時 |
|---|---|---|---|
| 氏名・生年月日 | パスポート | Final Excel List | 空欄、赤色セルにして確認 |
| フリガナ | Final Excel List | なし | 空欄、赤色セルにして確認 |
| 出生地 | パスポート | なし | 空欄、赤色セルにして確認 |
| 本国住所 | 履歴書 | なし | 空欄、赤色セルにして確認 |
| 職歴 | 履歴書 | なし | 空欄、赤色セルにして確認 |
| パスポート番号 | パスポート | なし | 空欄、赤色セルにして確認 |

## 4. 実行手順

1. 対象フォルダ内の対象者フォルダを確認する。
2. 各人のパスポートを読み取る。
3. Final Excel Listから氏名とフリガナを照合する。
4. 履歴書から本国住所と職歴を読み取る。
5. 指定テンプレートをコピーする。
6. 対象者を番号順に並べる。
7. 各項目を入力する。
8. 職歴を古い順に整理する。
9. 書式・色・シート名・ファイル名を確認する。
10. 完成後チェックを実施する。

## 5. 項目別入力ルール

| 項目 | 入力元 | ルール |
|---|---|---|
| 氏名 | パスポート | アルファベットを正確に入力 |
| フリガナ | Final Excel List | 一致する氏名の行を使用 |
| 生年月日 | パスポート | YYYY/MM/DD |
| 出生地 | パスポート | Place of birthを入力 |
| パスポート番号 | パスポート | 文字を変更しない |
| 職歴 | 履歴書 | 学歴を除外し、古い順 |
| 職歴期間 | 履歴書 | YYYY/MM〜YYYY/MM |
| 未確認項目 | なし | 勝手に推測しない |

## 6. 固定値・空欄ルール

- 明示された `0` は `0` を入力する
- 明示された `無` は `無` を入力する
- 空欄指定の項目には `0` や `無`を入れない
- 不明な情報は推測せず、空欄にして報告する

## 7. 出力ルール

- 指定テンプレートの列・行・書式を維持する
- シート名を変更しない
- 黄色セル・オレンジセルの意味を維持する
- 出力はプロジェクトフォルダ直下に保存する
- 出力ファイル名はプロジェクト名から作成する

## 8. 送信前チェック

- [ ] 氏名・フリガナ・生年月日が原資料と一致している
- [ ] パスポート番号・有効期限が一致している
- [ ] 職歴に学歴が混ざっていない
- [ ] 職歴が古い順になっている
- [ ] 空欄・0・無の使い分けが正しい
- [ ] 黄色セル・オレンジセルが正しい
- [ ] Excelで開ける
